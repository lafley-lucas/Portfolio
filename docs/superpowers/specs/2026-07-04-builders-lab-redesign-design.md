# 포트폴리오 리디자인 — "빌더의 실험실 (The Builder's Lab)"

- **날짜**: 2026-07-04
- **상태**: 사용자 승인 완료 (디자인 단계)
- **대상 파일**: `index.html` (단일 파일, 전면 리디자인)

## 배경과 목표

현재 `index.html`은 밝은 베이지 톤의 "calm luxe" 라이트 테마다. 사용자는 다음을 원한다:

- 더 혁신적이고 창의적인 디자인 (레퍼런스: Gustaf Furusten Portfolio — Awwwards, 미니멀 + 타이포 중심 + 실험적 애니메이션)
- 동적이지만 **보기 쉬운** 화면, 세련된 무드
- 이미지/영상이 동적으로 반응하는 느낌
- "독창적인 창의성"이라는 본인의 포인트가 디자인 자체로 드러날 것

## 비주얼 아이덴티티

- **배경**: 깊은 웜 차콜 (`#0d0c0a` 계열). 기존 그레인 오버레이(SVG 노이즈)는 다크 톤에 맞게 유지 (`mix-blend-mode` 조정).
- **타이포그래피**:
  - Fraunces (세리프, 이탤릭 액센트) — 유지
  - Pretendard (본문 한글) — 유지
  - **IBM Plex Mono 추가** — 레이블, 수치, eyebrow, "실험 데이터" 텍스트에 사용. 실험실 무드의 핵심 장치.
- **컬러 시스템**:
  - 텍스트: 웜 오프화이트 / 뮤트 그레이
  - 공통 액센트: 기존 브라스/골드 (`#c9a668` 계열로 다크 대비에 맞게 밝기 상향)
  - **프로젝트별 고유 액센트 1색** — 카드 UI와 해당 제너러티브 비주얼이 같은 색을 공유:
    - groom·pick: 웜 앰버

## 구조

섹션 구성과 **모든 한국어 콘텐츠 텍스트는 현재 그대로 유지**한다 (nav → hero → about → projects → experience → links → footer). 바뀌는 것은 표현(테마, 비주얼, 인터랙션)이다.

### 시그니처 모멘트 5개

1. **히어로 캔버스**: 뷰포트 전체 배경에 커서 반응형 입자 플로우 필드. 입자는 은은히 흐르고, 커서 주변에서 휘어지고 모인다. 이름 타이포는 스태거 리빌. 모바일에서는 터치 이동에 반응.
2. **프로젝트별 전용 제너러티브 비주얼**: 각 프로젝트 카드 상단에 라이브 Canvas. 화면에 보일 때만 구동, 호버 시 반응 강화.
   - **groom·pick**: 점묘로 그린 추상 얼굴 윤곽 + 수평 스캔라인이 훑으며 눈썹·피부 분석 마커 표시. 호버 시 스캔라인이 커서 y좌표를 따라감.
   - **NewsLens**: 문장 조각(대시 입자)이 좌측에서 흘러들어와 FACT / CLAIM / OPINION / FRAMING 4개 컬러 레인으로 분류되어 정렬됨.
   - **플러피**: 마감 시계 원호가 도는 동안 빵 입자들이 폐기선에 닿기 전 바구니 쪽으로 구출됨.
   - **뭐먹을래**: 메뉴 점들이 원형 룰렛으로 회전하다 감속, 하나가 선택되어 발광. 주기적으로 반복.
3. **스크롤 연동 타이포**: 섹션 대제목(h2)이 스크롤 진행에 따라 자간·수직 위치가 미세하게 변화.
4. **마그네틱 인터랙션**: 주요 버튼·링크가 커서 근접 시 살짝 끌려옴 (pointer:fine 환경에서만).
5. **스크롤 프로그레스 바**: 유지, 골드 라인.

## 가독성 · 접근성 보장

- 본문 텍스트는 캔버스와 직접 겹치지 않는다 — 어두운 반투명 패널 위 고대비 텍스트. 예외는 히어로: 이름 타이포가 캔버스 위에 올라가되, 텍스트 영역 뒤에 어두운 스크림(radial dim)을 깔고 입자 밝기를 텍스트 주변에서 낮춰 대비(WCAG AA 이상)를 확보한다.
- 모든 캔버스는 `aria-hidden="true"` 장식 요소. JS 미동작 시에도 콘텐츠는 완전히 읽힌다 (프로그레시브 인핸스먼트).
- `prefers-reduced-motion: reduce` 시: 모든 애니메이션 중지, 각 캔버스는 정적 1프레임 렌더로 대체.
- 모바일: 입자 수 축소, 마그네틱·커서 효과 비활성, 레이아웃 1열 스택.

## 기술 아키텍처

- **단일 `index.html` 유지**. 순수 vanilla JS + Canvas 2D. 라이브러리·빌드 도구·WebGL 없음.
- **공유 rAF 루프 1개**: 등록된 활성 캔버스만 매 프레임 업데이트.
- **IntersectionObserver**: 화면 밖 캔버스는 루프에서 제외(일시정지).
- **DPR 캡 2**: 레티나 대응하되 과도한 픽셀 부하 방지. 리사이즈 시 재계산.
- 각 비주얼은 독립 팩토리 함수: `makeHeroField(canvas)`, `makeGroompickScan(canvas)`, `makeNewslensSort(canvas)`, `makeFluffyRescue(canvas)`, `makeMwoRoulette(canvas)` — 공통 인터페이스 `{ update(dt), draw(ctx), onPointer(x,y), renderStatic() }`.
- 폰트: Google Fonts (Fraunces, IBM Plex Mono) + Pretendard CDN — 기존 로딩 방식 유지.
- Cloudflare Insights 스크립트 유지.

## 에러 처리

- Canvas/JS 실패 시: CSS 그라디언트 배경 폴백, 콘텐츠는 정적으로 완전 표시.
- `requestAnimationFrame` 미지원 고려 불필요 (모든 대상 브라우저 지원), 단 `IntersectionObserver` 부재 시 캔버스를 항상-활성으로 폴백.
